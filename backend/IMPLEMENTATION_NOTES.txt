## 🚀 Quick Start (3 Simple Steps)

### 1️⃣ Backend Setup
```bash
cd dashboard
pip install -r requirements.txt
python serve.py
```
✓ API running on http://127.0.0.1:8000

### 2️⃣ Frontend Setup (new terminal)
```bash
cd dashboard/frontend
npm install
npm run dev
```
✓ Dashboard running on http://127.0.0.1:3000

### 3️⃣ Test It
```bash
# Send sample flows
curl -X POST http://127.0.0.1:8000/classify \
  -H "Content-Type: application/json" \
  -d @sample_flows.json

# Open browser to http://127.0.0.1:3000
```
✓ Launch dashboard and see live data!

## 📝 Architecture Highlights

### Real-Time Processing Pipeline
1. NetFlow record arrives → /classify endpoint
2. Preprocess: Extract features, scale, map IPs
3. Encode: SAGELayer produces edge embeddings
4. Buffer: Rolling window of recent embeddings
5. Infer: TransformerAutoencoder reconstruction
6. Score: Error → anomaly_score → label
7. Respond: Return classification with metadata
8. Store: Add to recent_events for dashboard

### State Management
- Backend: In-memory stats, recent events (500 max)
- Frontend: React hooks (useState, useEffect, useCallback)
- Auto-refresh: Every 2 seconds via polling
- Data persistence: Optional (add Redis/DB later)

### Streaming Characteristics
- Window size: Configurable (default 32 flows)
- Step percent: 50% sliding overlap for smooth scoring
- Latency: ~100-200ms per batch (depends on batch size)
- Throughput: 1000+ flows/sec single worker
- Memory: ~300MB baseline

## 🔧 Customization

### Configuration Files
- `config_dashboard.yaml` - API, model, streaming settings
- `frontend/.env` - Backend URL, feature flags
- `vite.config.js` - Build and dev server settings

### Model Parameters
Edit serve.py to change:
- `edim_out`, `embed_dim`, `num_heads`, `num_layers` (transformer)
- `window_size`, `step_percent` (windowing)
- `threshold` (anomaly decision cutoff)

### UI Customization
- Colors: Edit root variables in `frontend/src/index.css`
- Components: Modify `frontend/src/components/*`
- API polling: Change refresh interval in `App.jsx`
